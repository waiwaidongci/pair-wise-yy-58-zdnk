# pair-wise-yy-58 大型构件吊装三维校核平台

围绕大型转换桁架吊装方案，提供三维场景、时间轴校核、冲突定位、条件评论和多角色签署工作流。页面支持拖动旋转吊装场景、编辑步骤参数、处理规则冲突、恢复本地草稿并锁定发布版本。

## 技术栈

Vue 3、Quasar、Pinia、Vue Router、Apollo Client、GraphQL、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

端口：`62058`

```bash
npm run build
```

数据草稿保存在浏览器 `localStorage`，Apollo 内存缓存保存吊装方案版本快照。

## 临时换主吊替换校核

`src/cranes.ts` 为纯领域模块（吊车档案、起重性能表插值、逐步骤荷载率/支腿反力/接地压力校核、档案差异、变更角色映射），`src/store.ts` 负责工作流，页面见左侧「换吊校核」：

- 发起替换先冻结方案版本与逐步骤校核基准（版本号、性能表版本、basis 签名留档）；
- 按每个步骤的作业半径插值查性能表得额定能力并核算荷载率；支腿反力折算为单腿接地压力，超过站位地基承载力即拒绝，并列出全部受影响步骤（其他步骤照旧）；
- 两人同时提交同一台吊车：先到者进入生效校核，后到者保留申请与差异，在先申请关闭后可转生效；同一人重复申请被拦截，不生成第二版；
- 吊车档案或步骤参数一变，生效申请立即按新参数重算，关联步骤的冲突与对应角色签署标记失效重签（失效角色由变更类型决定）；
- 确认链六项顺序确认，导出/保存或页面中断后从最后确认项续作；接受替换时步骤写入新设备快照并重算荷载率；
- 旧步骤没有设备快照时，在发起替换时先备份当前荷载率/半径/臂长到 `snapshot.backup` 再升级。
